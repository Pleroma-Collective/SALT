DayZ Toolkit 100% in your browser — no uploads, no network

DayZ Toolkit

Mission and config validators that run entirely on your computer. Files never leave your machine — every check below happens in your browser tab, with hard size limits and DayZ-specific structure rules (class names, roots, coordinates, map bounds).

Validate

XML Validator

Well-formedness plus DayZ structure rules for types.xml, events, globals, spawnables, presets and more. Safe cleanup download.

 Validate + Split

JSON Validator & Splitter

Strict JSON parsing with error location, formatting report, pretty-print download — and split any top-level array by count or size.

 Validate

Mission Validator (ZIP)

Drop a mission .zip (or a folder of loose files): every XML/JSON/init.c is checked, the mission structure is verified, and coordinates are tested against map bounds.

 Audit

Duplicate Classname Checker

Find duplicated type/group/event names across your types.xml, cfgspawnabletypes.xml, mapgroupproto.xml and friends — the #1 mission merge breaker.

 Audit

Event Conflict Check

Cross-checks cfgeventspawns.xml and cfgeventgroups.xml: shadowed names, invalid or out-of-bounds positions, and lootmin/lootmax inversions.

 Calculate · admin

Loot Probability Calculator

Chance to find any item per building category, from your server’s types.xml — quick answers from the extracted catalog, or drop your own types.xml. The math is shown. Admin access required (server spawn rates are private).

 Convert

PAA ↔ PNG Map-Tile Converter

Drop .paa tiles, a map .pbo (DayZ 1.30 uncompressed), or .png images — lint + preview per tile, convert to PNG and back (DXT1/DXT5 auto), zip download.

 Generate

Loadout Generator

Compose a player spawn config in the kitty_loadouts / CE format — pick items from your server’s extracted catalog, set quantities and spawn weights, preview the JSON, download the file.

 Generate

Spawnabletypes Generator

Compose a CE cfgspawnabletypes.xml — pick entity types from your server’s extracted catalog, set damage, hoarder, cargo presets and part groups, preview the validated XML, download the file.

 Browse

Loadout Browser

All server-curated player loadouts — holiday sets first, then themed and vanilla-enhanced. One click copies the full spawn config JSON for pasting into a mission.

Hosted-server operators: the authenticated Mission Doctor inside the dashboard validates your live Nitrado mission files the same way. These public tools are for local work — merging mods, authoring events, preparing a mission before you upload it.
