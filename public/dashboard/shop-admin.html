Minimum map clearance reserved around each rental placement. This is separate from DayZ CE radii.

📦 Child element <child type="..." max min lootmax lootmin>

A JSON array enables multiple event children (objects, guns, magazines, or event-group names). Leave blank to use Item Class and the child fields above.

This is where you set up event groups: multiple objects with relative X/Y/Z offsets in one event, plus optional secondary spawns. Offsets are relative X/Y/Z coordinates inside this object group. Each child type remains an object. A true spawnsecondary flag calls the event's <secondary> event from events.xml at that child offset; it does not directly place animals, infected, or NPCs.

Each Type MUST inherit DayZ's EffectArea class — a wrong class can crash mission startup. Entries are companions to this event (offsets are relative to the event position), not standalone; they are removed with the event on refund, cancel, or expiry.

Entries land in the shop-owned cfggameplay file and its registration; reversal is supported via tracked _shopEntryId — test with one cheap entry first.
